# workout-vibes

Vibe coded workouts: a simple weekly workout and meal planner.

- **Today**: today's planned workout and meals, macros vs. targets
- **Workouts / Meals**: build a Mon–Sun plan
- **Log**: record sessions (pre-filled from the plan) and browse history
- **Progress**: top-set and body-weight charts
- **Settings**: lb/kg, daily macro targets, sample plan, JSON backup/restore

Data lives in your browser's localStorage; use Settings → Export JSON to back it up.

```sh
npm install
npm run dev    # start the dev server
npm test       # run tests
npm run build  # type-check and build to dist/
```
